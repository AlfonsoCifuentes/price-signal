# PRICE / SIGNAL — narration to record (English, first person)

Generated from `script_master.json` (the single source for narration, captions and timing). Edit there, then run `python tools/build_timeline.py`.

**How to record:** one take per scene, in a quiet room, phone or USB mic 15–20 cm away. Name files `01.wav` … `13.wav` (film) and `v01.wav` … `v05.wav` (vertical). Leave a second of silence before and after each take; `prepare_voice.py` trims it. If a take runs longer than the scene, that's fine: the scene stretches to fit. Don't rush to hit the timing.

**Delivery:** calm, curious, matter-of-fact. It's a walkthrough, not an advert. Never say or imply this was work for a real publisher or employer.
